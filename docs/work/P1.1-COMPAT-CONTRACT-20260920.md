# P1.1 — Freeze the compatibility observation contract (2026-09-20)

## What

Closed the Gate B contract item **P1.1: freeze the compatibility observation
contract**. The flat compatibility record emitted by `build_ledger.py` and read at
the compile boundary was previously an unwritten implicit contract
(`SCHEMA.md` §7 items 1/4/5: "still Gate B work"). It is now explicit,
version-pinned, and machine-checked.

## Deliverables

1. **Documented envelope + major/minor policy** — `docs/COMPATIBILITY.md`:
   - the v0 envelope (`generated_at`, `config_path`, `entry_count`, `entries[]`);
   - the exact ordered 36-field entry list with semantic roles;
   - a semver major/minor/patch policy and migration notes;
   - producer guidance (optional `format` / `schema_version` annotation).
2. **Golden fixture preventing field-meaning drift** —
   `tests/fixtures/compat-contract.json` + `tests/test_compat_contract.py` assert
   `ledger.models.CSV_FIELDS == fixture entry_fields` exactly (order + names), so a
   rename, reorder, removal, or unapproved addition fails CI.
3. **Explicit unsupported-major behavior** — `ledger/compat_contract.py`
   (`LedgerCompatError` with stable codes) wired into the compile boundary:
   - unsupported `format` -> `COMPAT_FORMAT_UNSUPPORTED`;
   - unsupported schema **major** -> `COMPAT_MAJOR_UNSUPPORTED` (refuse to guess);
   - same-major newer minor tolerated (additive);
   - missing version marker defaults to supported v0 (current producer unchanged).

## Why

The R0 live proof and Wave 1/2 identity work depend on a stable read of the flat
compatibility output. Without a frozen contract, a future or external producer
could change field meanings and the compiler would silently reinterpret them. The
freeze makes drift fail loudly instead.

## Verification

- Full suite: `python3 -m unittest discover -s tests` -> **112 tests pass**
  (102 before + 10 new).
- CLI unsupported-major path: `ledger compile` with a `schema_version: 9.0.0`
  input exits `2` and prints `COMPAT_MAJOR_UNSUPPORTED: ...` (stable code) rather
  than compiling.
- `build_ledger.py` output surface unchanged (producer emits no version marker;
  absence = supported v0). Compatibility tests untouched and green.
